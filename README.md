# Node.js Learning

My practice repo for the Node.js + MongoDB program (React team upskilling).

## Setup

```bash
nvm use        # picks the Node version from .nvmrc
```

Each exercise is a separate Node project with its own `package.json`. Go into the folder and follow its README.
